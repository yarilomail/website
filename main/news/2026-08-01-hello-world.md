# YariloMail website launched

*1 August 2026*

yarilomail.org is now the home of YariloMail, the open-source mail server written in Go for Kubernetes. Release news is published here.

The documentation is at [doc.yarilomail.org](https://doc.yarilomail.org/latest/), the source code at [github.com/yarilomail/yarilo](https://github.com/yarilomail/yarilo), and the source of this website at [github.com/yarilomail/website](https://github.com/yarilomail/website).
